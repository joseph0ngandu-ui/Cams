System Features

Everything a professional needs.
Nothing they don't.

sensors UDP · BONJOUR

Zero-Config Discovery

Bonjour publishes _cams-video._udp automatically. OBS finds your device in seconds — no IP addresses to type, no ports to configure.

memory HEVC · H.264

Hardware Encoding

VideoToolbox drives the Apple Neural Engine for hardware HEVC (primary) with H.264 fallback. 2-second GOP, CABAC entropy, CBR at up to 50 Mbps for 4K 60fps.

person_search HARDWARE · VISION

Subject Tracking

Hardware Center Stage on supported iPads. Software fallback via VNDetectHumanRectanglesRequest with α=0.15 exponential smoothing for all other devices.

analytics 1s WINDOW

Live Telemetry HUD

Real-time outgoing bitrate, packet drops per second, and thermal state — all updated on a 1-second rolling window. Thermal throttle reduces bitrate automatically: 50% at Serious, 75% at Critical.

settings_remote UDP 8889

Bi-directional Control

OBS can remotely set focus lock, exposure lock, quality preset, subject tracking, and request keyframes. The iOS app surface updates in real time with a distinct visual state for OBS-originated commands.

stacked_bar_chart JITTER · DECODE

OBS Reassembly Pipeline

The OBS plugin reassembles fragmented UDP frames, reorders via a jitter buffer, and hardware-decodes with FFmpeg. Loss events trigger automatic keyframe requests within 1000ms.

Wire Format

The 21-byte header.

Every UDP packet begins with a fixed 21-byte big-endian header, followed by raw NAL payload bytes. All fragments for one encoded frame share the same sequence number.

OBS Studio Integration

Native plugin. First-class source.

The Cams OBS plugin is a native obs_source_t. It handles Bonjour browsing, UDP reassembly, jitter buffering, hardware decode, and bi-directional control entirely within OBS.

Receive Pipeline
1
NetworkListener

POSIX UDP socket on port 8888 with SO_RCVBUF=8MB. Validates packet headers and routes to reassembler.

2
FrameReassembler

Reconstructs fragmented encoded frames. Fires a LossCallback on 1000ms timeout — triggers keyframe request to iOS.

3
JitterBuffer

Reorders out-of-sequence frames using the 32-bit sequence number from the packet header.

4
VideoDecoder

FFmpeg with hardware acceleration decodes HEVC/H.264 and outputs frames via obs_source_output_video.
