Privacy Policy

Effective: 1 June 2025 Version 1.0
verified_user
Summary

Cams does not collect, store, or transmit any personal data to external servers. All video, audio, and control data stays on your local network. The app has no analytics, no crash reporting to third parties, and no user accounts.

1. What Cams Is

Cams is an iOS application that captures video from your device camera and streams it to OBS Studio over your local Wi-Fi network using a custom UDP protocol. Cams also includes an OBS Studio plugin that receives this stream.

Cams is free and open source software, distributed under the MIT License. The source code is publicly available at our GitHub repository.

2. Data We Do Not Collect

Cams does not collect any of the following:

Video or audio content from your camera
Personal identifiers (name, email address, Apple ID, device ID)
Location data
Usage analytics or behavioral telemetry
Crash reports sent to external services
IP addresses of your devices
Network topology information

3. How Video Data Is Handled

Video captured by the iOS app is encoded using the device's hardware VideoToolbox encoder (HEVC or H.264) entirely on-device. The encoded stream is transmitted as UDP packets directly from the iOS device to the OBS Studio instance on the same local network.

No video data is transmitted to any server, cloud service, relay, or third party at any point. The data path is exclusively:

iPhone camera → VideoToolbox encoder → UDP → OBS Studio (local network)

Cams does not store, buffer to disk, or log any video data on either the iOS device or the machine running OBS.

4. System Permissions

Cams requests the following iOS system permissions. All are required for core functionality and none grant us access to your data.

photo_camera Camera

Required to capture video frames. We never access your Camera Roll, photos, or any previously captured media.

wifi Local Network

Required to publish a Bonjour service so OBS can discover the device, and to send UDP packets to OBS on the same network. We never communicate beyond your local network.

5. Third-Party Services

Cams does not integrate with any third-party SDKs, analytics platforms, advertising networks, or crash-reporting services. The application has no internet-facing network connections other than the local UDP streams described above.

This website is hosted as a static site. Standard web server access logs may be maintained by the hosting provider. We do not use cookies, JavaScript tracking, or any analytics on this site.

6. Children's Privacy

Cams does not knowingly collect any personal information from anyone, including children under 13. Because we collect no data, we are COPPA-compliant by design.

7. Changes to This Policy

If we ever change this policy in a material way (for example, if a future version of Cams added cloud features), we will update the Effective Date above and note the changes in the application release notes. Continued use of the application after the update constitutes acceptance of the revised policy.

8. Contact

Questions about this policy can be directed to us via a GitHub Issue at the Cams repository. We do not maintain a dedicated privacy email address because we collect no personal data to inquire about.
